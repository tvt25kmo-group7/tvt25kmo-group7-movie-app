10 · Learning

Challenges & lessons

Technical challenge

We built backend features in parallel, but our routing approaches did not match.

Lesson: We aligned the new route with the existing Node.js handler structure.

Teamwork challenge

Finding shared meeting times was sometimes difficult. Parallel work also caused conflicts when several people changed the same files.

Lesson: We needed clearer coordination before editing shared code.
